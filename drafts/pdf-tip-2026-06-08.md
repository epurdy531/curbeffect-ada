Document Accessibility Tip of the Day

📃Topic: Fill in the document Title in Word's file properties before exporting📄

When a PDF opens, assistive technology announces the document by its Title metadata — not by its file name. If that Title is blank, screen readers fall back to something unhelpful like "Document1.pdf" or whatever string the export happened to copy out of the first line. Worse, the PDF/UA expectation is that the viewer displays the document Title in the window title bar rather than the file name, and that switch only happens when a real Title is present. Setting it in Word before you export is the easiest place to fix this — it is one field, and it carries straight through into the exported PDF's metadata.

In Word, open the File menu and choose Info. On the right side under Properties you will see a Title field — type the human-readable name of the document there, for example "FY2026 Annual Budget Report" rather than "budget_v7_FINAL_revised". You can also click Properties, then Advanced Properties, to open the full dialog and edit Title, Subject, and Author at the same time. Save the document, then export to PDF using Save As PDF or Export with the "Document structure tags for accessibility" option checked.

Two practical follow-ups. First, open the resulting PDF in Acrobat, go to File, then Properties, and confirm the Title is populated on the Description tab — if it is blank, the export did not pick it up and you will need to type it directly into Acrobat's Title field. Second, on that same Properties dialog, switch to the Initial View tab and set "Show" to "Document Title" instead of "File Name"; this is the DisplayDocTitle flag, and without it a conforming viewer will keep showing the file name even when the Title metadata is correct.

Spending ten seconds on the Title field in Word saves the remediation step of opening every exported PDF in Acrobat to type it in by hand — and it means the first thing a screen reader user hears is the actual name of your document.

🔍 Reference: for the exact normative wording, see PDF/UA clause 7.1 in your ISO 14289-1 copy.
