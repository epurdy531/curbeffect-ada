Document Accessibility Tip of the Day

📃Topic: Building multilevel lists in Word so nesting survives the PDF export📄

You already know to use Word's bullet and numbered list buttons instead of typing dashes or "1." by hand. The next trap is nesting: a list with sub-points under its main points needs to export as a real nested list, not as one flat run of items that happens to be indented.

When you have sub-items, don't reach for the Tab-then-space trick or the Increase Indent button to fake a second level. Use Word's Multilevel List button (on the Home tab, next to the bullet and numbering buttons), then press Tab at the start of a line to demote an item to the next level and Shift+Tab to promote it back. Word records that as a true parent-child list structure.

That structure is what carries into the export. When you Save As or Export to PDF with tags enabled, a properly nested Word list becomes nested list tags (an inner list sitting inside its parent list item), so a screen reader announces "list of 3 items" and then, inside item 2, "list of 2 items." A screen reader user can tell how deep they are and how the sub-points relate to the point above them.

If nesting was faked with plain indentation, the exported PDF flattens it: every item reads at the same level, the relationship between a point and its sub-points is lost, and fixing it in the PDF means rebuilding the list nesting tag by tag in the tag tree. Getting the levels right in Word with Tab and Shift+Tab avoids that remediation entirely.

One quick check before exporting: click into each list and confirm the demoted items actually changed bullet or number style (for example a filled bullet becoming a hollow one, or 1/2/3 becoming a/b/c). If the marker never changes when you press Tab, Word is only indenting the text, not nesting the list — set it up again with the Multilevel List button.

🔍 Reference: for the exact normative wording, see PDF/UA clause 7.6 in your ISO 14289-1 copy.
