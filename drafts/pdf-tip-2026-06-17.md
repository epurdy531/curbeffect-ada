Document Accessibility Tip of the Day

📃Topic: Tab order in interactive PDFs📄

When a keyboard or screen-reader user presses Tab through a PDF form or interactive page, they are following an order set by the document — not by where things sit on the screen. If that order does not match the visual reading flow, people end up jumping from the name field to a checkbox three sections down, then back up to address, and the form becomes effectively unusable without a mouse.

In Acrobat Pro, open the Page Thumbnails panel, right-click each page, choose Page Properties, and on the Tab Order tab select Use Document Structure. That tells the page to follow the tag tree you have already built, so tab order, reading order, and visual order all line up. Avoid the Unspecified option — it leaves the order up to the viewer and often defaults to row-then-column based on coordinates, which breaks the moment a field is even slightly out of grid.

Then verify it by hand. Click into the first field and press Tab repeatedly through the whole document, watching the focus ring move from one control to the next. If focus skips a field, lands on a decorative element, or jumps backward, fix the tag order in the Tags panel or reorder the fields in the Prepare Form view — the visual layout alone will not correct it. Tab order needs to be set on every page that has form fields, links, or other interactive controls, not just the first one.

🔍 Reference: for the exact normative wording, see PDF/UA clause 7.18 in your ISO 14289-1 copy.
