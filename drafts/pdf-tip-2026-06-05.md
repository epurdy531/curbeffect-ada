Document Accessibility Tip of the Day

📃Topic: Setting the document language in Word so the exported PDF reads in the right voice📄

Screen readers decide how to pronounce a document by reading its language metadata. If that metadata is missing or wrong, English text gets read with French phonetics, Spanish quotes get pronounced as English, and the listening experience falls apart. Word controls this at the source, and the language you set there carries straight into the exported PDF — so getting it right in Word saves you from patching it tag by tag in Acrobat later.

To set the overall document language, open the Review tab, click Language, then Set Proofing Language, and choose the document's primary language. Tick "Set As Default" if you want every new document to start with that language. This sets the default language for the whole file, which is what becomes the PDF's top-level /Lang entry when you export.

For passages written in another language — a Spanish quotation in an English report, a French program name, a Latin phrase — select just that run of text and use the same Set Proofing Language dialog to assign the secondary language to the selection only. Word stores that as a localized property on the selected run, and Word's PDF export carries it through as a /Lang attribute on the corresponding tag so screen readers switch voices for exactly that passage and then switch back.

A few practical notes. Proper nouns and short borrowed terms usually do not need language tagging — only mark genuine prose in another language. Avoid using the language tool to "fix" pronunciation of acronyms or product names; that is what an /ActualText override is for, not a language switch. And when you copy and paste from another document, paste as plain text or recheck the language on the pasted run, because the original language attribute often comes along for the ride and quietly turns part of your document into something a screen reader will mispronounce.

Doing this in Word means the exported PDF arrives with both the document-level language and any in-line language switches already in place — no manual tag attribute editing required in Acrobat.

🔍 Reference: for the exact normative wording, see PDF/UA clause 7.2 in your ISO 14289-1 copy.
