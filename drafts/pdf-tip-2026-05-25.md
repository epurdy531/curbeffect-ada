Topic: Exporting the right way from Word so the PDF keeps its tags

How you turn a Word document into a PDF decides whether you spend ten minutes or two hours remediating it later. Use File > Save As (or File > Export) and pick PDF, then open the Options dialog and confirm "Document structure tags for accessibility" is checked — that single setting carries Word's headings, lists, tables, and alt text straight into the PDF as a real tag tree. Never use File > Print and choose a "PDF" or "Microsoft Print to PDF" printer: that path rasterizes the layout and throws away every tag, leaving you to rebuild the structure by hand. The payoff is that all the accessible authoring you already did in Word survives the export, so the file arrives mostly tagged and you only need to verify and polish rather than start from zero.

Reference: for the exact normative wording, see PDF/UA clause 7.1 in your ISO 14289-1 copy.
