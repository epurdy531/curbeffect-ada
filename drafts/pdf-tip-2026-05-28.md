Topic: Decorative images and artifacts

Not every image in a PDF carries meaning. Page borders, background watermarks, divider lines, repeated logos in a corner, and ornamental flourishes are visual decoration, not content — and screen readers should skip right past them. In Acrobat's Tags panel, mark these as artifacts rather than tagging them as <Figure> with empty alt text. (Use the Content panel or the "Change Tag to Artifact" command from the Tags panel context menu; in newer Acrobat builds you can also right-click the object in the reading order tool and choose Background/Artifact.) An empty-alt <Figure> still announces "figure" to assistive tech and clutters the reading order; a true artifact disappears from the accessibility tree entirely. The rule of thumb: if removing the image would not change what a sighted reader understands, it is decorative and belongs as an artifact.

Reference: for the exact normative wording, see PDF/UA clause 7.1 in your ISO 14289-1 copy.
