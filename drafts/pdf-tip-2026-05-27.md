Topic: Use Word's built-in Heading styles for every heading

In Word, apply the built-in Heading 1, Heading 2, Heading 3 styles (from the Styles gallery on the Home ribbon) to every heading instead of just bolding text or bumping up the font size. Visually the two can look identical, but only the named styles carry real structure: when you export with Save As PDF or Export, Word turns Heading 1 into an H1 tag, Heading 2 into H2, and so on, producing a properly nested heading tree that screen-reader users navigate by jumping heading to heading. Manually styled "headings" export as ordinary body paragraphs, so the PDF has no outline at all and you end up rebuilding every heading by hand in Acrobat's tag tree. If you don't like Word's default look, right-click a heading style and choose Modify to change the font, size, and color — the style stays a real heading while looking however you want. Keep the levels in order (don't skip from H1 to H3 for appearance), and the exported PDF starts out with clean heading structure and remediation work you never have to do.

Reference: for the exact normative wording, see PDF/UA clause 7.4 in your ISO 14289-1 copy.
