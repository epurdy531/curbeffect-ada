Document Accessibility Tip of the Day

📃Topic: Setting language in Word — fix the whole-document default, then flag each foreign-language passage📄

A screen reader decides how to pronounce your text from the language Word records in the document, and that setting rides straight through to the exported PDF. Get it right in Word and the PDF's language markers come out correct with no cleanup; leave it wrong and every quote, name, or borrowed phrase gets read in the wrong accent.

Start with the whole document. Select all the body text (Ctrl+A), then go to Review > Language > Set Proofing Language and confirm the correct language is chosen — and importantly, that "Detect language automatically" is turned OFF. Auto-detect is the usual culprit behind a document that carries three or four stray languages you never intended; it guesses per paragraph and quietly mislabels short lines. Turning it off and setting one deliberate language gives the exported PDF a single, reliable top-level language.

Then handle the exceptions. For any run of text genuinely written in another language — a Spanish program name, a French motto, a Latin legal term — select just those words, open Review > Language > Set Proofing Language again, and assign that passage its actual language. Word writes this as a per-span marker, so the PDF ends up with the right language on that stretch and the default everywhere else. This is the piece that hand-remediation in Acrobat is tedious to add later, so setting it in the source saves you tagging each span by hand.

One caveat: proper names, product names, and organization names that happen to look foreign usually should stay in the document's main language — mark a passage only when it's really written in another language, not just because a word looks unfamiliar.

🔍 Reference: for the exact normative wording, see PDF/UA clause 7.2 in your ISO 14289-1 copy.
