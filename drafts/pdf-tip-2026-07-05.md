Document Accessibility Tip

📃Topic: Set the document Title in Word before you export📄

A PDF's title bar — and the first thing a screen reader announces when the file opens — comes from the document's **Title** property, not its file name; leave it blank and users hear something like "final_v3.pdf" or nothing useful at all. Set it in Word before exporting: go to **File ▸ Info** and fill in the **Title** field (or **File ▸ Properties ▸ Summary**), then use **Save As PDF / Export** so the value carries into the PDF's metadata. One catch — many viewers still display the file name until "Display Document Title" is turned on in the PDF (in Acrobat: **File ▸ Properties ▸ Initial View ▸ Window Options ▸ Show: Document Title**), so flip that flag and confirm after exporting. It's a ten-second edit in Word that spares you a metadata fix later and immediately orients anyone using assistive technology.

🔍 Reference: for the exact normative wording, see PDF/UA clause 7.1 in your ISO 14289-1 copy.
