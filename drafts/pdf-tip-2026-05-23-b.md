Topic: Text and declaring the document's natural language

A screen reader has to know what language a document is in before it can pronounce a single word correctly — the same letters are spoken very differently in English, Spanish, or French. Set the document's default language at the file level so assistive technology starts with the right pronunciation rules and voice; an untagged or wrong default is a common reason a clean-looking PDF reads back garbled. Then handle the exceptions: when a passage switches languages — a Latin phrase, a French quotation, a Spanish street name — mark that span with its own language so it isn't read with the wrong accent. While you're confirming language, also confirm the words are real, extractable text rather than pictures of text: select a line and copy it out, and if nothing comes through or it pastes as gibberish, the page needs OCR or corrected Unicode mapping before any language setting will help.

Reference: for the exact normative wording, see PDF/UA clause 7.2 in your ISO 14289-1 copy.
