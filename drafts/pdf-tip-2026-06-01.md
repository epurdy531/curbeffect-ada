Topic: Build real tables in Word with a designated header row

When a Word document needs a table, build it with Insert > Table and pick the row and column count — never fake one by lining up tabs, spaces, or text boxes. Once the table is in place, click into it, open the Table Design tab, and check "Header Row" so the top row is marked as the repeating header; if the table spans pages, also open Table Properties > Row and tick "Repeat as header row at the top of each page." Keep the structure simple: avoid merged or split cells, avoid blank rows used as visual spacers, and do not nest tables inside other tables. When the document is exported to PDF with tags enabled, Word carries that structure through as a proper Table tag with TR rows, a TH header cell with the correct scope, and TD data cells — which is exactly what a screen reader needs to announce each value with its column heading. Faked tables, by contrast, export as a loose run of text and almost always need full manual rebuilding in Acrobat, so a few minutes of structure in Word saves an hour of remediation later.

Reference: for the exact normative wording, see PDF/UA clause 7.5 in your ISO 14289-1 copy.
