Topic: Figures, images, and alternative text

When you remediate a PDF, tag every meaningful image as a Figure and give it alt text that conveys what the image communicates in context — not a literal description of pixels. In Acrobat's tag tree, a Figure tag needs an Alternate Text value (right-click the tag, choose Properties, and fill the Alternate Text field, or use the Reading Order tool's "Figure" button and then edit the alt text). Keep it concise and purposeful: a screenshot illustrating a step should describe the step it shows, and a chart should state the takeaway and key numbers rather than "bar chart." Don't restate text that already appears in the caption or body, and never leave the alt text empty on an informative image — a screen reader will then announce only "figure" or fall back to the filename, which tells the reader nothing. Also make sure each Figure sits in the correct spot in the reading order so the description is announced where it belongs, not stranded at the end of the page.

Reference: for the exact normative wording, see PDF/UA clause 7.3 in your ISO 14289-1 copy.
